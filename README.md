# homebrew-mona
This is Mejistus' homebrew tap.

## Formulas

| Formula | Description |
| --- | --- |
| [`oplire`](Formula/oplire.rb) | OpenCode limit reset and Anthropic proxy bridge via Cloudflare WARP |
| [`fantastic-i3`](Formula/fantastic-i3.rb) | Tiling desktop for macOS in the style of i3: yabai, skhd and SketchyBar |
| [`sidex`](Formula/sidex.rb) | VS Code workbench running on Tauri instead of Electron |
| [`zhihu-cli`](Formula/zhihu-cli.rb) | Zhihu command-line tool — search, browse hot list, ask, post pins/articles |

## Usage

```bash
brew tap mejistus/mona
brew install mejistus/mona/oplire
```
